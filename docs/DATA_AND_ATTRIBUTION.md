# Data and attribution

This repository is a public research summary rather than a raw-data or software release.

## Included

- selected figures generated from the dissertation analysis;
- experimental and analysis methodology;
- fitted results;
- limitations relevant to the interpretation of those results.

## Not included

- raw LAPPD or HRPPD detector datasets;
- raw-data decoding software supplied by collaborators;
- internal collaboration material;
- working ROOT/C++ and Python source code;
- figures whose redistribution status is unclear.

The MSc dissertation records that raw detector data were decoded with software supplied by **Dr Dan Foulds-Holt**, and that HRPPD ROOT data used in the initial analysis were provided by **Dr Dan Foulds-Holt and George Ramsey**. Those materials are not redistributed here.

The laser-profile characterisation, motorised-stage control, detector-analysis workflow and dissertation-level ROOT/Python fitting work presented here were carried out by **Saqib Umair** as part of the MSc project.

External figures used only for scientific context in the dissertation or defence presentation are intentionally omitted from this public repository.
