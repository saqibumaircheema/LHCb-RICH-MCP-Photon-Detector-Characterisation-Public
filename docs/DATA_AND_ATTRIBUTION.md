# Data and attribution

This repository is a public research summary, not a raw-data release.

## Included

- figures generated from the dissertation analysis;
- the experimental and analysis methodology;
- fitted results and their interpretation;
- limitations relevant to the reported measurements.

## Not included

- raw LAPPD or HRPPD detector datasets;
- raw-data decoding software supplied by collaborators;
- internal collaboration material;
- working ROOT/C++ and Python source code;
- figures whose redistribution status is unclear.

The MSc dissertation records that raw detector data were decoded with software supplied by Dr Dan Foulds-Holt, and that HRPPD ROOT data used in the initial analysis were provided by Dr Dan Foulds-Holt and George Ramsey. Those materials are not redistributed here.

The analysis, laser-profile characterisation, motorised-stage control and dissertation-level ROOT/Python fitting work were carried out by Saqib Umair as part of the MSc project.

The public figures in this repository are restricted to analysis outputs and schematics produced for the project. External figures used for scientific context in the dissertation and defence presentation are intentionally omitted from this repository.
